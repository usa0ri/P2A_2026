# Overview

Ribo-seq analysis for Wu and Uematsu et al., 2026.

# Requirements

All the environments of the analysis steps were developed as docker images.

Host requirements:

+ Ubuntu 22.04.5 LTS
+ Docker version 28.2.2
+ VScode version 1.109.4 with the following extensions:
  + Dev Containers v0.442.0
  + Docker v2.0.0

# Contents

All the steps were done in a remote container of VScode defined in `devcontainer`. The required python packages for a conda environment are listed in `devcontainer/environment.yml`. Building the devcontainer will take a few minutes.

The figures were made by a custom python code `make_figures.py`. The shared functions are written in python scripts under `myRiboSeq`.

The plasmid reporter sequences are available under `reporter_sequences`.

The alignment of reads to the plasmid DNA reporter sequences was performed using the custom python and cython scripts used in our previous study (https://github.com/usa0ri/DecodingMemory2026/tree/main).

The sample datasets are under `data_example`.

+ `find_subsequence_counts`: The read count information from Ribo-seq `.fastq.gz` file generated by the custom cython script. 
+ `find_subsequence_query`: The k-mer information used for the alignment.
